## Design Context

### Users
Engineering teams from solo devs merging at midnight to SRE leads checking architecture risk before release. They're technical, time-pressed, and scanning for signal — not browsing. The interface is consumed during code review workflows, incident triage, and architecture planning sessions. Dark offices, split screens, terminal beside browser.

### Brand Personality
Sharp, watchful, surgical. Argus is the eye that never closes — precise cuts through noise, never bloated, always purposeful. The interface should feel like a well-calibrated instrument: nothing extra, nothing missing. Every pixel earns its place.

### Aesthetic Direction
**Tactical terminal** — dark, monospace-driven, sharp edges. Inspired by Vercel's dashboard and Hyper terminal: dark void backgrounds, amber accents as the single signal color, monospace typography as the primary voice. Zero radius on containers (`--radius: 0`). No rounded corners, no gradients on surfaces, no decorative shadows.

The current foundation is strong: amber-on-void palette, OKLCH colors, noise texture, zero-radius. The gaps are in execution — too many generic SaaS patterns that undermine the tactical identity.

### Design Principles

1. **Instrument, not dashboard** — every surface should feel like a precision tool readout, not a marketing metric card. Denser information, fewer decorative containers.
2. **Amber is signal, not decoration** — amber accents mark active/important states only. Rest is monochrome void. If everything glows, nothing glows.
3. **Monospace as primary voice** — JetBrains Mono is the face of the product. Headings, labels, data, navigation — all mono. Display font ONLY for wordmark and marketing hero.
4. **Zero radius, sharp edges** — `--radius: 0` everywhere. No rounded corners on cards, buttons, or containers. Sharp = precise.
5. **Information density over whitespace** — users are engineers scanning for signal. Compact, scannable, data-forward. More Bloomberg, less Notion.

### Typography

- **Display/Wordmark**: **Stencil** (Google Fonts) — military/tactical designation plate. Used ONLY for the ARGUS wordmark and marketing hero headlines.
- **UI Primary**: JetBrains Mono — all dashboard headings, labels, data, navigation. This IS the brand voice.
- **Body/Prose**: Geist Sans — only for long-form text (descriptions, explanations, docs content). Never for UI chrome.
- Scale: fixed rem (not fluid) — dashboard product UI. 5-step scale with 1.3× ratio.

### Color

- **Primary signal**: `oklch(0.47 0.157 37.304)` — amber/orange. Used for: active states, critical paths, the wordmark, live indicators, pulse states. Never for decoration.
- **Void**: `oklch(0.147 0.004 49.3)` — near-black with warm undertone. All backgrounds.
- **Charcoal**: `oklch(0.214 0.009 43.1)` — card/surface lift. Subtle.
- **Iron**: `oklch(1 0 0 / 10%)` — borders. Minimal, structural.
- **Text**: `oklch(0.986 0.002 67.8)` — near-white with warm tint.
- **Slate text**: `oklch(0.714 0.014 41.2)` — secondary labels, metadata.
- All neutrals warm-tinted toward amber hue (~37-49 range). No cool grays.
- Severity colors: red (critical), amber (warning), blue (suggestion), green (praise). Sparse — small labels, dots, thin borders. Never large background fills.

### Anti-Patterns (Banned)

- No `border-left` / `border-right` > 1px as accent stripes
- No gradient text (`background-clip: text`)
- No rounded corners (enforce `--radius: 0`)
- No glow effects on static elements (only active/pulse states)
- No Syne font anywhere
- No generic icon-above-heading card layouts
- No sparklines as decoration
- No glassmorphism/blur surfaces

### Resolved Design Decisions

| Component | Decision |
|-----------|----------|
| Display font scope | Wordmark + marketing hero only. Dashboard headings → JetBrains Mono |
| Display font | Stencil (Google Fonts) — military designation plate aesthetic |
| Sidebar active state | Amber text + bg shift (no border-left) |
| Comment severity | Full 1px border in severity color around entire comment (no border-left) |
| Hero title | Amber text-stroke/outline on Stencil font — stamped metal effect |
| Glow effects | Pulse states only (live indicator, active pipeline dot). Everything else flat. |
| Stat metrics | Bare readouts — no card containers. Label above, value below. Terminal style. |
| Lists (reviews, patterns, insights) | Table/row lists — compact, no per-item cards |
| Noise texture | Keep at 3% opacity |
| Eye symbol | Keep draw animation on marketing page |
| Live indicator | Amber pulse dot (not green). Remove "LIVE" text. |
| Severity palette | Keep 4-color system (red/amber/blue/green) |
| Empty states | Terminal prompt style: `// No reviews yet. Install →` |
| Mobile | Full parity — not read-only |
| Review detail page | Two-panel: file tree left, detail right (IDE-like) |
| Verdict display | Large mono score numeral + verdict text beside |
| Motion | Full system: load reveals + hovers + state transitions. ease-out-quart. No bounce. |
| Architecture canvas | Keep React Flow but restyle: zero-radius nodes, mono labels, thin border severity |

### Motion

- Full motion system: staggered load reveals, subtle hover state shifts, state transitions
- Pulse only for live/active indicators — never static glow
- `ease-out-quart` for natural deceleration. No bounce/elastic.
- Respects `prefers-reduced-motion`
